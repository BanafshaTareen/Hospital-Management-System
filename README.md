# Hospital Management Portal

A multi-page hospital management portal developed using **HTML**. The project provides a simple web interface for presenting hospital information, medical services, doctors, appointment forms, reports, and other hospital-related information.

## Features

- Hospital home page
- About and organization information
- Medical services and charges
- Doctors directory with qualifications and experience
- Patient appointment form
- Hospital gallery
- Contact information
- Admin login interface
- Patient appointment records page
- Navigation between multiple web pages

## Pages

The project contains the following pages:

- **Home** – General hospital information and featured services
- **About** – Organization history, mission, vision, achievements, and director message
- **Services** – Available medical services and charges
- **Doctors** – Doctor information including qualifications and experience
- **Appointment** – Form for patients to enter appointment details
- **Gallery** – Hospital and equipment images
- **Contact** – Hospital contact details and location section
- **Admin** – Admin login interface
- **Reports** – Sample patient appointment records

## Technologies Used

- HTML
- HTML Forms
- HTML Tables
- Embedded Images and Links
- Multi-page Website Navigation

## Project Structure

The website is organized into multiple HTML files:

- `index.html`
- `about1.html`
- `services.html`
- `doctors.html`
- `appointment.html`
- `gallery.html`
- `contact.html`
- `admin.html`
- `report.html`

## Current Functionality

This project focuses on the **front-end structure of a hospital portal**. The appointment and admin login forms demonstrate the user interface but are not connected to a backend server or database.

## Purpose

This project was developed to practice fundamental web development concepts, including:

- Creating multi-page websites
- HTML forms and input controls
- Tables and structured data
- Hyperlinks and page navigation
- Images and multimedia elements
- Organizing information across multiple web pages

## Running the Project

1. Download or clone the repository.
2. Open `index.html` in a web browser.
3. Use the navigation menu to access the different sections of the portal.
